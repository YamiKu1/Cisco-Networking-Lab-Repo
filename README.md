# Enterprise Network Infrastructure Lab

## Overview

Designed and configured a simulated small-business network using Cisco Packet Tracer.

The project demonstrates fundamental networking and infrastructure administration skills including IPv4 addressing, subnetting, VLANs, trunking, inter-VLAN routing, DHCP, ACLs, and network troubleshooting.

## Network Architecture

The network contains separate VLANs for:

* IT — VLAN 10
* HR — VLAN 20
* Sales — VLAN 30
* Management — VLAN 40

## Troubleshooting

The project includes intentionally created network failures to demonstrate troubleshooting methodology.

Examples include:

* Incorrect IP configuration
* Incorrect VLAN assignment
* Trunk configuration failure
* Incorrect default gateway
* Routing/subinterface failure

For each issue, I documented the symptoms, troubleshooting process, root cause, resolution, and verification.
